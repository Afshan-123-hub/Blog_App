# 📒 Ledger — A Blog Worth Keeping

A minimalist blog application where every post is a numbered entry in a running ledger. No algorithms, no reshuffling — just honest, chronological storytelling.

---

## ✨ Features

- 🔐 **User Authentication** — Register, Login, Logout
- ✍️ **Create Posts** — Write blog entries with titles, tags, and content
- 📖 **Read Posts** — View all posts in chronological order
- 🗑️ **Delete Posts** — Remove unwanted entries
- 📊 **Dashboard** — Track total posts, word count, and latest entry
- 🏷️ **Tags** — Organize posts with custom categories
- 📱 **Responsive** — Works on mobile, tablet, and desktop
- 💾 **Local Storage** — All data saved in your browser
- 🔄 **Real-time** — Instant updates without page refresh
